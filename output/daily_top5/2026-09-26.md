## 1. メタプラネット(3350)はビットコインのサポート割れ局面で「寄り付きの一番安いところ」を狙う
- 📺 **動画**: [環境分析 2026/7/13](https://www.youtube.com/watch?v=TMkSmYQz7Ig) / メタプラネット応援チャンネル / 2026-07-14 08:22 / 再生74回
- 💰 **アイディア**: メタプラネット(3350)を買うなら、ビットコインが下落してサポートラインを試しに行く局面に狙いを絞り、その日の「寄り付き」で仕込む。特にビットコインが62,000ドルのサポートを陰線で割り込み、59,000ドルへ下押しするようなタイミングでは、寄り付き直後に大きく下げやすいので、そこを拾いに行く。
- 🎯 **背景**: メタプラネットはビットコインを大量保有する事実上のビットコイン・プロキシ銘柄で、株価はビットコイン価格に強く連動する。だからこそ「いつ買うか」を暗号資産側のチャートで決められる。ビットコイン下落 → メタプラ寄り付きで最も下がる、という値動きの癖を利用し、日中高値づかみを避けて底値近辺を取りに行く発想。
- 📌 **根拠**:
  - ビットコインが62,000ドルのサポートを陰線で試しており、割り込めば59,000ドルまでの下押しが視野に入る局面（動画07:22, 19:28）
  - 「ビットコインが下がった時に、寄りで結構下がりやすいので、寄りで一番下がったところで取りに行く」という具体的なエントリー手法の言及（20:00）
- 💡 **着眼点**: 一般には「ビットコイン関連株はビットコインと一緒に動くから怖い」と語られがちだが、ここではその連動性を弱点ではなくエントリータイミングの設計図として使っている。指標を眺めて待つのではなく、暗号資産のサポート水準と「寄り付きが最も下がる」という時間帯の癖を組み合わせ、押し目の入り口を一点に絞り込んでいるのが面白い。

## 2. NISA口座を「将来の社会保険料の高額請求」に備える保険として積み立てる
- 📺 **動画**: [環境分析 2026/7/13](https://www.youtube.com/watch?v=TMkSmYQz7Ig) / メタプラネット応援チャンネル / 2026-07-14 08:22 / 再生74回
- 💰 **アイディア**: 資産運用の非課税枠であるNISA口座を、単なる節税ではなく「将来の社会保険料負担増に対するヘッジ資産」と位置づけて使う。特定口座での運用益とは別に、NISA口座で長期保有資産（ゴールド等）を積み立てておき、万が一、特定口座の利益をきっかけに社会保険料が跳ね上がったときの支払い原資として確保しておく。
- 🎯 **背景**: 将来、特定口座の運用益が社会保険料の算定に反映される制度変更が入るのではないか、という懸念が出発点。もしそうなれば、投資で利益を出すほど社会保険料が膨らむという逆説が生じる。一方NISA口座の利益は非課税で、社会保険料の算定基礎にも含まれない。この「算定から外れる」性質を、税メリットではなくリスクヘッジの器として捉え直している。
- 📌 **根拠**:
  - 「特定口座の利益で（社会保険料が）上がるのは嫌だ」という制度リスクへの問題意識（10:51）
  - 「NISA口座の利益は非課税で、社会保険料にも換算されない」ため算定から外れるという事実（11:01）
  - 「特定口座で社会保険が発生して、ものすごい額の請求が来た時に、NISA口座でバックアップを持っておけばヘッジ・保険になる」という活用構想（11:40）
- 💡 **着眼点**: NISAは普通「税金がかからないお得な枠」として語られるが、ここでは「社会保険料の算定から外れる」という別の性質に光を当て、値上がり益を狙う口座ではなく将来の請求ショックを吸収する保険口座として設計している。同じ制度でも、節税ではなく“逆進的な負担増からの防波堤”という角度で使う発想がユニーク。前提として、NISAの非課税や社会保険料算定除外のルール自体が変われば効かなくなる点は要注意。

## 3. 半導体大手(SKハイニックス)の業績を、暗号資産まで含むリスク資産全体の調整シグナルとして監視する
- 📺 **動画**: [環境分析 2026/7/13](https://www.youtube.com/watch?v=TMkSmYQz7Ig) / メタプラネット応援チャンネル / 2026-07-14 08:22 / 再生74回
- 💰 **アイディア**: 半導体・メモリ大手（SKハイニックスなど）の業績ニュースを、単なるハイテク株の材料としてではなく、ナスダックから暗号資産まで含めた「リスク資産全体」の調整が始まるかどうかの先行シグナルとして監視する。半導体主導で売りが出たら、株価指数だけでなくビットコインやメタプラのようなリスク資産のポジションも一段警戒に切り替える。
- 🎯 **背景**: 直近の下げは、SKハイニックスの業績が予測を下回ったことがトリガーとなり、半導体メモリの売り → ナスダックなどハイテク株 → さらに暗号資産市場からの資金流出、という順に波及した。つまり半導体という一セクターの業績が、リスク資産全体のリスクオン/オフの起点として機能している、という見立て。
- 📌 **根拠**:
  - 「SKハイニックスの業績が予測より下回ったのが出て、半導体メモリの売りに影響した」という具体的なトリガーの特定（07:22）
  - 「半導体主導のマーケットから、今、全面的に暗号資産も主要株価指数も売られている」という波及経路の観察（07:22）
- 💡 **着眼点**: 半導体は普通「AI相場の主役」「景気敏感の代表」として語られるが、ここでは半導体を暗号資産まで巻き込むリスクオフの“最上流の蛇口”として位置づけている。株の材料と暗号資産の材料を別物として見るのではなく、メモリ大手一社の決算を横断的なリスク資産の温度計に読み替えている点が新しい。半導体決算カレンダーが、そのまま暗号資産の押し目・撤退判断の目安になる。

## 4. ゴールド(XAUUSD)は日足の押し目を待って、NISAで「脳死で長期運用」する対象として仕込む
- 📺 **動画**: [環境分析 2026/7/13](https://www.youtube.com/watch?v=TMkSmYQz7Ig) / メタプラネット応援チャンネル / 2026-07-14 08:22 / 再生74回
- 💰 **アイディア**: ゴールド(XAUUSD)を、日足チャートの押し目買い水準への到達を待ってから、1年以上の長期保有前提で買っていく。個別に売買タイミングを刻むのではなく、NISA口座を使って手間をかけずに長期で積み上げる“守りのコア資産”として位置づける。
- 🎯 **背景**: 社会保険料負担の増加や制度変更への備えとして、非課税で長く持てる資産を確保したいという発想が土台にある。ゴールドはその「長期で脳死運用できる」中核候補。ただし足元は日足で陰線が続いており、下落トレンドが継続するリスクがあるため、飛びつかず押し目水準への到達を待つのが条件。
- 📌 **根拠**:
  - 「ゴールドはもうそろそろ買いたい感じになってきている。長期で、脳死で運用できるようなゴールドを買っていこうか」という長期スタンスの言及（06:02, 11:20）
  - 短期的には陰線が続き下落トレンド継続の可能性があるという自覚（本人がリスクとして明示）
- 💡 **着眼点**: ゴールドは普通「インフレヘッジ」「有事の金」として語られるが、ここでは日本の社会保険料・税制リスクへの長期の受け皿として、しかもNISAの非課税枠と組み合わせて“手間をかけない守りの資産”に落とし込んでいる。売買のうまさで稼ぐ資産ではなく、制度リスクに対して淡々と積み上げる器として扱う割り切りが、同じ金投資でも角度が違う。
